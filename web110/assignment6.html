In the Internet Services activity, I learned that the Internet is used for many different services, not just looking at websites. There are services for communication, sharing information, transferring files, and connecting to other computers. I learned that different Internet services have different purposes depending on what someone needs to do. I can use what I learned when choosing the right Internet service for school or everyday communication. In the VoIP Messaging activity, I learned that people can communicate over the Internet by using voice calls and messaging services. VoIP allows people to make calls through an Internet connection instead of using a traditional phone line. I also learned that messaging makes it easy to communicate quickly with other people. I can apply this by using online communication tools to stay in contact with classmates, teachers, friends, and family. In the Screen Sharing Remote Desktop activity, I learned that it is possible to access another computer from a different location. Remote desktop allows someone to see and control a computer through an Internet connection. I learned that this can be useful when someone needs to access their computer remotely or help another person with a computer problem. I could use this in school when working remotely or when someone needs to help me solve a computer problem. In the FTP activity, I learned about transferring files between computers using a network. FTP can be used to move files from one computer to another computer or server. I learned that file transfer is important when working with files stored in different locations. I can apply this knowledge when uploading, downloading, or moving files for school assignments and other projects. Overall, this lesson taught me more about how the Internet is used for communication, remote access, and transferring files. These activities helped me better understand how different Internet tools work and how they can be used in everyday situations.
