Before this lesson, I knew that using the internet could have some risks, but I did not know how many different ways people could try to steal information. One thing that stood out to me was phishing, which happens when someone pretends to be a trusted company or person to get private information. I also learned more about malware and how it can affect a computer without the user realizing it. I can use this information when checking emails, opening links, or downloading files. Even if a message looks real, I should still check it carefully before trusting it. Another thing I learned was how web browsers handle personal information. I already knew that browsers save history, but I did not know as much about cookies and cache. Cookies can remember information about websites, while cache stores parts of websites to help them load faster. I also found out that private browsing does not completely hide my online activity from websites or internet providers. This is useful to know because I use the internet for school and other everyday activities. I can protect my privacy by checking browser settings, clearing saved information when needed, and keeping my browser updated. When learning about computer threats, I found out that viruses are only one type of malware. There are also threats like spyware, ransomware, and Trojan horses, which can cause different problems. For example, spyware can collect information, while ransomware can prevent someone from accessing their files. I knew that security software was important, but now I understand more about why it is needed. In the future, I will make sure my computer's security software stays updated and avoid downloading programs from websites I do not trust. Passwords were another important topic in this lesson. I have always known that passwords should be strong, but I learned why it is also important to use different passwords for different accounts. If someone gets access to one password, they might try using it on other accounts too. Password managers can help keep track of passwords, and multi-factor authentication provides extra protection by requiring another form of verification. I can use these methods for my school email and other personal accounts to help keep my information safe. Overall, this lesson gave me a better understanding of internet security. I already knew some basic ways to stay safe online, but now I understand more about how security threats work and how to prevent them. These are useful skills that I can use every day, especially when using my computer for school, personal accounts, and future work.
