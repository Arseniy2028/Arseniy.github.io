I have used browsers like Chrome and Safari for a long time, but I never really thought about how they worked. This will be useful for me because I am taking a web development class and will need to make sure my websites work correctly in different browsers. I also learned about developer tools, which can be used to look at the code behind a website and find problems. I think this will be helpful when I start making my own websites because I can use these tools to find mistakes and understand why something is not working correctly.
